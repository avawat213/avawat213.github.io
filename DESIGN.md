# Design Plan

## Page Structure
- Navigation
- Header Section (Name and Course)
- About Section
- Projects Section

## Layout Choices
I chose a single-page layout to keep the website simple and easy to navigate.
Navigation links scroll to each section on the same page.

## Design Rationale
A single-page design ensures all required content is accessible without switching pages.
The card layout keeps the content organized and visually appealing while maintaining readability on both desktop and mobile devices.
